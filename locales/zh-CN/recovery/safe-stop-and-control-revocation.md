# 安全停止与控制撤销

当必须不再允许某个智能体、云端会话、集成、规则或通道请求物理动作时，使用本手册。

AetherEdge 为特定资源提供受治理的禁用操作，但尚未公开一个通用的软件急停能力。已投运的物理急停、设备联锁或站点运行规程，仍然是即时危险控制的首要权威。

## 遏制

1. 当人员或设备可能面临风险时，首先执行站点安全规程或启用物理联锁。
2. 在调用方权限或凭据所属的权威边界上撤销它。
3. 禁用范围最窄的受影响控制面：某个下游集成、某条动作路由、某条规则或某个通信通道。
4. 只使用带当前修订、明确确认和持久审计的类型化应用命令。不要直接写入 SHM、SQLite、提供方 API 或协议寄存器。
5. 记录操作标识、`request_id`、结果修订、终态审计状态和运行时对账状态。

## 结果未知

如果命令超时、响应丢失、报告审计不完整，或者运行时是否收敛未知，不要自动再次提交。请读取权威的期望修订、资源状态、审计轨迹和物理观测。在人工解决相互冲突的证据之前，保持该路径处于禁用状态或物理隔离状态。

提供方接受、MQTT 确认和边缘端命令回执，都不能证明物理过程已经进入安全状态。请按照站点的投运策略核对相关传感器或设备的反馈。

## 恢复

只有在引发问题的凭据或策略缺陷已经修复、确定性安全行为健康、运行时投影与期望状态一致，并且有人明确批准该变更之后，才能恢复访问，而且每次只恢复一项能力。
