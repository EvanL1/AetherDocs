# MCP 工具参考

由 `scripts/gen-mcp-docs.sh` 根据服务器的 `tools/list` 生成。共 45 个工具；标记为**写入**的工具只有在服务器以 `--allow-write` 运行时才会注册。启用写入之前，请先阅读[应用与智能体的安全操作](/zh/guides/safe-operations)。

## 告警

### `alarms_events`（只读）

列出历史告警事件，可按规则/类型/级别/关键字过滤

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `event_type` | 字符串/空值 | 否 | 按事件类型过滤："trigger"（告警触发）或 "recovery"（告警恢复） |
| `keyword` | 字符串/空值 | 否 | 在规则名称、通道、点位中按关键字搜索 |
| `level` | 整数/空值 | 否 | 按告警级别过滤（1=低，2=中，3=高） |
| `page` | 整数 | 否 | 页码（从 1 开始） |
| `rule` | 整数/空值 | 否 | 按告警规则 ID 过滤 |
| `size` | 整数 | 否 | 每页条数 |

## 通道

### `channels_create`（**写入**）

通过经过身份验证、显式确认并经审计的 io.channel.manage 应用命令创建通信通道。这是一项高风险、非幂等的投运变更；enabled 默认为 false。成功时可能报告降级的运行时投影或不完整的完成审计：请检查 request_id、resulting_revision 和 reconciliation_required。客户端不得自动重试。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `confirmed` | 布尔值 | 是 | 显式确认这项高风险的通道投运变更。 |
| `description` | 字符串/空值 | 否 | 可选的描述 |
| `enabled` | 布尔值 | 否 | 通道是否在创建后即启用。默认为 false，因此创建本身不产生任何效果。 |
| `id` | 整数/空值 | 否 | 显式指定的通道 ID；省略则自动分配 |
| `name` | 字符串 | 是 | 通道名称 |
| `parameters` | - | 是 | 协议特定的连接参数（结构取决于 `protocol`） |
| `protocol` | 字符串 | 是 | 协议标识符，例如 "modbus"、"iec104" |

### `channels_delete`（**写入**）

通过经过身份验证、显式确认并经审计的 io.channel.manage 应用命令删除通信通道。存在动作路由引用时会产生冲突，绝不会静默级联删除。这是一项高风险、非幂等的投运变更；成功时可能报告降级的运行时投影或不完整的完成审计。请检查 request_id、resulting_revision 和 reconciliation_required。客户端不得自动重试。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `channel_id` | 整数 | 是 | 通道 ID |
| `confirmed` | 布尔值 | 是 | 显式确认这项高风险的通道投运变更。 |
| `expected_revision` | 整数 | 是 | 必需的期望状态比较并设置修订，取自最近一次通道读取（最小为 1） |

### `channels_disable`（**写入**）

通过经过身份验证、显式确认并经审计的 io.channel.manage 应用命令禁用通信通道。这是一项高风险、非幂等的生命周期变更；降级的运行时投影会被接受，并且需要对账。请检查 request_id、resulting_revision 和 reconciliation_required。客户端不得自动重试，完成审计不完整时也是如此。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `channel_id` | 整数 | 是 | 通道 ID |
| `confirmed` | 布尔值 | 是 | 显式确认这项高风险的通道投运变更。 |
| `expected_revision` | 整数 | 是 | 必需的期望状态比较并设置修订，取自最近一次通道读取（最小为 1） |

### `channels_enable`（**写入**）

通过经过身份验证、显式确认并经审计的 io.channel.manage 应用命令启用通信通道。这是一项高风险、非幂等的生命周期变更；等待激活或降级的结果会被接受，这意味着需要对账，并不证明连通性。请检查 request_id、resulting_revision 和 reconciliation_required。客户端不得自动重试，完成审计不完整时也是如此。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `channel_id` | 整数 | 是 | 通道 ID |
| `confirmed` | 布尔值 | 是 | 显式确认这项高风险的通道投运变更。 |
| `expected_revision` | 整数 | 是 | 必需的期望状态比较并设置修订，取自最近一次通道读取（最小为 1） |

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `confirmed` | 布尔值 | 是 | 显式确认这项高风险的规则策略变更。 |

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `confirmed` | 布尔值 | 是 | 显式确认该规则可以下发真实的设备命令。 |
| `rule_id` | 整数 | 是 | 规则 ID |
