# aether-auth-jwt

共享内核实现：在面向应用的服务边界上以失败关闭的方式验证访问 JWT。

它只接受使用所配置的服务器密钥签发的 HS256 访问令牌，校验有界的声明和过期时间，并把已签名的角色映射到固定的 Aether 应用权限集。它本身不对能力做授权；应用策略仍然负责执行权限、确认、修订号、幂等和审计要求。

这是内核内部的基础设施，不是扩展，也不是受支持的独立认证产品。

```bash
cargo test -p aether-auth-jwt
```
