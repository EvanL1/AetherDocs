# 安全策略

> 本页是英文原文的简体中文说明。带标签版本中的英文规范、JSON Schema、测试夹具和 TCK 共同构成规范性依据；中文页面只用于任务路由和人工审查。

发现疑似漏洞时，请通过仓库的私密安全通告流程报告。不得在公开问题中提交凭据、私钥、可重放证明、客户制品，或针对已经部署系统的利用记录。

最新发布版本是 `v0.1.0-alpha.4`；`0.1.0-alpha.5` 是尚未发布的开发目标。两者都处于实验阶段，都有意不定义可用于生产的共享消息代理认证流程或带签名的持久确认。不得把这些不完整的配置档部署为信任边界。

契约解析器必须限制输入大小、嵌套深度、字符串、数组和内存分配；必须在语义验证前拒绝重复键和无效 Unicode；绝不能记录签名材料或原始证明。有效的载荷身份或 MQTT 主题不等于经过认证的发布方身份。

把每个 MQTT 前缀视为一个授权命名空间。网关标识在该命名空间内必须唯一；多租户部署必须隔离租户或项目的前缀，或者使用云端全局唯一的网关标识；消息代理主体必须限制在确切的命名空间以及网关的发布、订阅主题内。前缀和主题仍然不提供任何网关认证。在应用保持不变的四字段线协议身份之前，先根据这一可信入口命名空间选择持久重放存储分区。绝不接受载荷自行选择的命名空间，绝不跨命名空间复用记录，也绝不执行不分区的全局查询。

对于默认关闭的网关签名提案，在执行持久查询、新鲜度检查或重放检查前，先验证签名、有效密钥、消息代理主体命名空间、当前有效会话、网关身份、会话代次和凭据代次。只能使用已经冻结的交付或心跳签名投影。心跳时间检查使用显式评估时间和协商得到的会话间隔；uint64 溢出失败关闭，重放绝不延长存活状态。

只有业务效果和重放记录已经原子持久化，交付重放记录才视为已提交。只完成认证、仅预留或仍处于待定状态的记录绝不能绕过首次接纳的到期检查。已提交的不可变交付只能重新绑定到严格更高的当前会话代次，并且在重新签发该会话的回执前，新绑定必须已经持久化。检查持久重放记录的到期状态前，先拒绝同代次的会话变化、会话代次回退、凭据代次变化和任何不可变字段的变化。

alpha.4 的 `session-accepted` 没有签名，也不绑定其质询或客户端随机数，因此不能排除延迟的跨握手响应。这一点和未签名的持久确认共同阻断生产认证。

TCK 解码器的非传输预算只是防御性默认值，不代表嵌入式目标可以按最大值分配内存。语言绑定可以根据明确记录的资源约束更早拒绝输入。CloudLink MQTT 消息始终受配置档中的 262144 字节上限约束。

Thing Model 动作只是能力声明。语言绑定不得把它们暴露为直接物理操作，也不得绕过应用层受治理作业和边缘策略路径。

接入拓扑和观测对象绝不能包含提供方 URL、访问令牌、刷新令牌、Cookie、凭据引用、任意提供方属性集合或直接服务调用。这些值留在边缘本地配置和机密存储中，不得进入测试夹具、日志、审计载荷、提示词或云端投影。

CloudLink 接入扩展继承已经认证的外层网关会话，绝不把提供方凭据移入保持不变的公开载荷。拒绝超过限制的完整拓扑，而不是拆分或部分应用它；观测批次只能在封装之前划分为相互独立的有界批次。

独立的受治理控制扩展默认关闭；在云端动作提议密钥的签发、轮换、撤销以及边缘验证方归属实现之前，它不具备生产就绪条件。它只接受封闭的
`device.power.set.v1` 意图。拒绝任何由调用方提供的提供方域、操作、参数对象、URL、令牌或未声明动作。调用提供方前，先验证当前会话、强制到期时间、意图摘要、显式确认、确切拓扑目标、持久作业重放绑定和边缘本地策略。提供方接受请求绝不能证明物理完成。

只有在确认到该位置为止的每个位置都已经持久保存，或者已被接纳的数据丢失证据覆盖之后，才能把持久确认当作累计删除边界。存在未声明缺口时，禁止推进游标和删除待发送队列数据。
