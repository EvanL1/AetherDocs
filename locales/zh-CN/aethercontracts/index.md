# AetherContracts 产品概览

> 本页是面向中文用户的说明。带标签版本中的英文规范、JSON Schema、测试夹具和 TCK 才是规范性依据。

AetherContracts 是 AetherEdge、AetherCloud 与独立实现共同使用的公开、语言中立互操作权威。

规范定义行为，JSON Schema Draft 2020-12 定义结构接纳，测试夹具固定可观察的示例，黑盒 TCK 提供可执行证据。产品本地副本或语言绑定永远不能成为第二套事实来源。

## 当前发布版本

`v0.1.0-alpha.4` 冻结了实验性的 CloudLink 线协议、配置档与 TCK 契约面，并提供 TypeScript、Rust、C 与 C++ 的夹具绑定。它不是生产 CloudLink 切换版本。

该发布版本在经过签名、摘要锁定的制品中保留了历史上的使用方名称 AetherIot。仓库改名为 AetherEdge 之后，这些字节仍然不可变。后续发布版本可以更新产品展示名称，而不改变协议标识。

请阅读 [AetherContracts 仓库](https://github.com/EvanL1/AetherContracts)、[兼容性矩阵](https://docs.aetheriot.ai/zh/compatibility/version-matrix/)和[边缘端、公共协议与云端联动任务](https://docs.aetheriot.ai/zh/guides/edge-contracts-cloud/)。
