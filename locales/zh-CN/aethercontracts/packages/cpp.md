# AetherContracts C++ 基础库

> 权威来源：[AetherContracts](https://github.com/EvanL1/AetherContracts/blob/main/packages/cpp/README.md)。本页是其简体中文说明；带标签版本中的英文规范、JSON Schema、测试夹具和 TCK 才是规范性依据。

C++17 目标 `AetherContracts::cpp` 是 C99 核心之上的轻量非持有包装层。它不实现第二套解析器或协议契约。完整 JSON 支持和生产级 CloudLink 一致性仍在规划中；它的实验性夹具接口委托给 C99 核心。
