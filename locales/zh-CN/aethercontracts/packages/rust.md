# AetherContracts Rust 基础库

> 权威来源：[AetherContracts](https://github.com/EvanL1/AetherContracts/blob/main/packages/rust/README.md)。本页是其简体中文说明；带标签版本中的英文规范、JSON Schema、测试夹具和 TCK 才是规范性依据。

`aether-contracts` 是 AetherContracts 的实验性 Rust 基础绑定。它目前提供带语言中立失败结果的规范 `u64` 解析，并执行公开的 CloudLink 夹具清单。它不是完整的生产 Thing Model、认证或传输编解码器。
